# 🐾 API de Adoção de Animais

A **API de Adoção de Animais** foi desenvolvida com o propósito de **organizar e otimizar o processo de adoção e os eventos de adoção de animais**.  
O sistema permite o registro e gerenciamento de **animais, instituições, adotantes e voluntários**, tornando o fluxo de informações mais ágil, transparente e centralizado.

---

## 🎯 Objetivo

Fornecer uma **solução back-end funcional** que implemente todas as operações do **CRUD (Create, Read, Update, Delete)** para diferentes entidades envolvidas no processo de adoção, contribuindo para a gestão eficiente de dados e para a ampliação da adoção responsável.

---

## 🧩 Funcionalidades

- 🐶 **Animais** — cadastro, listagem, atualização e exclusão de animais disponíveis para adoção.  
- 🏠 **Instituições** — gerenciamento de ONGs, abrigos e protetores parceiros.  
- 👩‍🦰 **Adotantes** — registro de pessoas interessadas e acompanhamento de adoções realizadas.  
- 💪 **Voluntários** — controle de colaboradores e suas atuações em eventos.  
- 📅 **Eventos de Adoção** — criação e gerenciamento de ações de adoção organizadas pelas instituições.

---

## ⚙️ Tecnologias Utilizadas

| Categoria | Tecnologias |
|------------|-------------|
| **Backend** | Node.js / Express *(ou substitua conforme o stack real)* |

| **Arquitetura** | RESTful API |
| **Documentação** | Swagger / Postman |
| **Controle de Versão** | Git e GitHub |

---

## 🔄 Operações CRUD

A API realiza as quatro operações fundamentais de manipulação de dados:

| Operação | Descrição | Exemplo |
|-----------|------------|----------|
| **Create** | Cadastra novos registros | Adicionar um novo animal ou adotante |
| **Read** | Consulta registros existentes | Listar todos os animais disponíveis |
| **Update** | Atualiza informações | Editar dados de uma instituição |
| **Delete** | Remove registros do sistema | Excluir um evento de adoção |
